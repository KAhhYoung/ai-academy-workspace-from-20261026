# 막혔을 때 먼저 확인할 것

| 현상 | 확인 방법 |
|---|---|
| NotImplementedError 또는 TODO 번호가 터미널에 표시 | 수강생용 미완성 블록입니다. 그 번호의 요구사항을 구현합니다. 서버 재설치 문제가 아닙니다. |
| /docs는 열리지만 내 API가 없음 | 현재 교시의 Route 등록과 심화 include_router TODO를 확인합니다. |
| ModuleNotFoundError | VS Code의 Python 선택, 가상환경, 실행 폴더를 확인합니다. |
| app 모듈을 찾지 못함 | 6·7교시 심화는 app 폴더 바깥의 프로젝트 루트에서 app.main:app으로 실행합니다. |
| Address already in use | 이전 교시 서버 터미널에서 Ctrl+C로 종료한 뒤 하나만 실행합니다. |
| 브라우저 연결 거부 | 서버가 떠 있는지·8000 포트가 맞는지 확인합니다. HTTP 404와 다릅니다. |
| 404 | Path·대상 ID·현재 교시에서 구현된 기능을 확인합니다. |
| 405 | 경로는 있지만 Method가 다릅니다. 주소창은 보통 GET입니다. |
| 422 | detail의 loc·msg를 읽어 Path·Query·Body 중 입력 위치를 찾습니다. |
| 500 | 서버 터미널을 확인합니다. TODO인지, 파일 경로·JSON 손상인지 구분합니다. |
| 값이 재시작 후 사라짐 | 같은 교시 폴더·같은 파일인지, reset을 실행했는지 확인합니다. |
| /docs가 빈 화면 | CDN 자원 접근 문제일 수 있습니다. 공통 안내의 표준 Python 요청 도구로 응답을 확인합니다. |

`.venv` 활성화가 막히면 시스템 실행 정책을 바꾸지 말고 가상환경 Python의 경로를 직접 사용합니다.
교시 폴더 기준: `..\..\.venv\Scripts\python.exe -m uvicorn main:app --reload`
심화 06·07만 끝의 모듈을 `app.main:app`으로 바꿉니다.

`knowledge.json`이 손상되었다고 무조건 빈 목록으로 덮어쓰지 마세요. 현재 파일을 먼저 보존하고 원인을 확인합니다.
초기화는 서버를 끈 뒤, 해당 폴더에서 `python reset_data.py --confirm-reset`을 명시적으로 실행합니다.
이 명령은 기존 파일을 타임스탬프 백업한 후 seed로 되돌립니다. 일일프로젝트의 두 번 재시작 사이에는 절대로 실행하지 않습니다.
