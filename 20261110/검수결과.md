# 실습자료 검수 범위

기본 15·응용 23·심화 30개의 Python TODO를 강사용 정답에 대입하면 모든 교시 앱이 같은 결과를 내는지 확인했습니다.
학생용은 미완성 상태이므로 일부 요청이 NotImplementedError 또는 미등록 Route로 실패하는 것이 정상입니다.

정답 앱의 CRUD·404·422·204·파일 저장·재시작 검증은 Linux·Python 3.13.5·FastAPI 0.128.2·Pydantic 2.13.5에서 통과했습니다.
실제 서버를 두 번 종료·재실행한 뒤 B의 수정·C의 삭제·A와 기존 지식 보존을 확인했습니다.
Windows·PowerShell 및 브라우저 UI 직접 조작은 미검증입니다.
이 환경의 DNS 제한으로 외부 패키지 저장소에서 새로 설치하는 과정은 검증하지 못했습니다. requirements는 실제 코드 실행에 사용한 조합입니다.

이것은 로컬 단일 프로세스 학습용입니다. 공개 서비스·인증·DB·RAG·Agent까지 완성한 것은 아닙니다.
