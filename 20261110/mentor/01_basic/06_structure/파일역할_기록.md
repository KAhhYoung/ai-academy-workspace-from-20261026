# 실습 06 · 파일 역할 설명 예시

- B06-R1: main.py의 @app.post("/api/knowledge", ...)는 POST와 경로를 create_knowledge 함수에 연결합니다.
- B06-R2: create_knowledge 안의 write_data(data)가 변경 내용을 저장하도록 호출합니다. storage.py의 write_data가 실제 JSON 기록·교체를 합니다. None을 반환하고 파일을 변경합니다.
- B06-R3: KnowledgeWrite는 입력 규칙, read_data/write_data는 파일 접근 동작, knowledge.json은 실제 저장된 데이터입니다.

질문: response_model을 선언하면 파일이 자동으로 저장될까요? 아닙니다. 저장 호출이 별도로 필요합니다.
기본필수에는 계층 재구성·테스트 작성을 요구하지 않습니다. 같은 코드를 읽고 설명하는 활동입니다.
