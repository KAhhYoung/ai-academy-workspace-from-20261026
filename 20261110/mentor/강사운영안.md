# 강사 운영안

## 기준과 범위

84장 PPT의 3단계·지식 관리 API·마지막 일일프로젝트를 따릅니다. 구판의 상품 예제나 별도 네 번째 난이도를 사용하지 않습니다.
기본필수도 CRUD 전부를 수행합니다. 응용은 TODO와 category 필터·함수 분리, 심화는 책임 분리와 임시 파일 테스트를 더합니다.
이 자료에서 새로 정한 것은 파일명·폴더·TODO 위치·구동 보조 도구입니다. 교안에 없는 인증·LLM·DB 구현을 필수로 넣지 않았습니다.

## 진행

| 교시 | 설명·시연 / 실습 | 활동 |
|---|---|---|
| 1 | 15 / 35분 | 플랫폼 목적·환경·health·/docs |
| 2 | 15 / 35분 | JSON 구조·목록·상세·404/422 |
| 3 | 20 / 30분 | Body 검증·생성·ID·저장 |
| 4 | 15 / 35분 | PUT·ID와 위치·수정 불변 조건 |
| 5 | 10 / 40분 | DELETE·빈 204·실패 보존 |
| 6 | 15 / 35분 | 기본 역할 읽기 / 응용 함수 분리 / 심화 Router 연결 |
| 7 | 10 / 40분 | 공통 계약 통합·기록·다음 수업 연결 |
| 8 | 6분 안내 + 40분 수행 + 4분 공유 | 나만의 지식 3개: A 유지·B 수정·C 삭제 |

합계 400분, 설명 110분·실습 290분입니다. 기본필수 학생에게 자동 테스트를 추가로 강제하지 않습니다.

## 독립 실행과 진도 복구

각 교시의 이전 기능은 완성 골격으로 제공하므로 앞 실습을 못 끝내도 다음 실습으로 이동할 수 있습니다.
이에 따라 학생은 다른 교시의 제공 코드를 참고할 수 있습니다. 이 자료는 시험용 정답 은닉 패키지가 아니라 수업용입니다.
두 서버를 동시에 띄우지 않습니다. 이동 전 Ctrl+C, 이동 후 폴더와 모듈 명령을 확인합니다.
08에는 새 main.py가 없습니다. 기존 07을 이어 사용하고 seed로 초기화하지 않습니다.

## 수강생용과 정답

동일한 BEGIN/END TODO ID, 파일·함수 위치를 유지했습니다. 강사용 주석은 핵심 개념에 더 자세한 해설을 둡니다.
수강생용은 문법 검사를 통과하지만 TODO가 미완성이면 해당 요청·테스트가 실패합니다.
학생의 NotImplementedError를 라이브러리 설치 오류로 오해하지 않게 첫 시간에 안내합니다.
metadata·include_router의 pass는 일부러 문법상 실행 가능한 자리표시자이며, 요구 기능은 아직 없습니다.

## 6교시의 차이

기본필수는 기존 main.py·storage.py를 읽고 파일역할_기록.md에 답합니다. 새 클래스·폴더 재설계가 없습니다.
응용은 queries.py의 선택·탐색 계산만 분리합니다. 심화는 app/main.py·schemas·routers·repositories를 연결합니다.
Template 비교는 별도 참고예제의 완성본을 짧게 시연하며 필수 구현·배점이 아닙니다.

## 8교시 채점

40점: 세 지식 생성·조회·B 수정·C 삭제.
25점: 두 번의 실제 서버 재시작 후 B 수정·C 삭제 유지와 A·기존 지식 보존.
15점: 201·204 빈 본문·404·422와 실패 시 파일 보존.
10점: 사용자·목적·요청→검증→저장→응답·플랫폼 내 역할 설명.
10점: 작업 위치·명령·실제 ID·예상/실제·파일 근거 기록.
자동화는 수강생 설명을 대신 채점하지 않습니다. 기본필수도 공통 만점이 가능합니다.

## 주요 오해와 질문

- POST 201을 적으면 저장도 되는가? 아니다. write_data를 별도로 호출한다.
- ID와 리스트 인덱스는 같은가? 아니다. 삭제 후 ID가 끊겨도 위치는 0부터 다시 이어진다.
- PUT에 content만 보내도 되는가? 현재 계약에서는 422. 세 필드를 모두 전송한다.
- GET []는 오류인가? category 결과가 없으면 200과 빈 목록이다.
- /docs 화면 새로고침은 서버 재시작인가? 아니다. Ctrl+C 후 같은 명령으로 새 프로세스를 띄운다.
- 임시 파일 TestClient 테스트가 재시작까지 검증하는가? 아니다. 별도 프로세스 확인이 필요하다.
- JSON 저장이면 이미 RAG인가? 아니다. 검색·생성·도구 실행은 이후에 연결한다.

## 참고 MVP

전체 구조 시연용입니다. 학생 패키지와 분리하여 언제 공개할지 선택할 수 있습니다.
공통 API·모델·저장 구조를 그대로 쓰며, 새로운 Service/DAO·인증·배포 계층을 불필요하게 추가하지 않았습니다.
