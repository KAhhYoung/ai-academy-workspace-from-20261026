## 실패·경계 검수

필수 값 누락, 빈 값, 길이 초과·최대 경계, 잘못된 JSON, 잘못된 Path, 없는 ID를 확인했습니다.
PUT은 ID·개수·next_id를 보존하고 DELETE는 빈 204·나머지 지식 보존·ID 미재사용을 확인했습니다.
제공 저장 코드의 교체 실패와 손상 파일도 내부 검수했습니다. 이를 학생의 새 필수 과제로 추가한 것은 아닙니다.

pytest 9.0.2 / httpx 0.28.1 / Jinja2 3.1.6.
요구 패키지 버전은 실제 실행 조합을 기록한 것이며 최신 버전이라고 단정하지 않습니다.

**Windows·PowerShell 직접 실행과 브라우저 Swagger UI 버튼 조작은 미검증**입니다. /docs HTML·OpenAPI·실제 HTTP 응답은 확인했습니다.
별도 가상환경에서 패키지 신규 다운로드를 시도했으나 이 실행 환경의 DNS 접근이 실패했습니다.
따라서 **외부 저장소에서의 신규 설치 성공은 확인하지 못했으며**, 위 설치된 패키지 환경에서 코드 실행을 검수했습니다. 로그: fresh_install_attempt.txt.
