# 실습 07 · 강사용 검수 예시

이 기록은 제작 시 Linux의 실제 Uvicorn 서버에서 실행한 결과입니다. 수강생의 실제 결과를 대신하지 않습니다.
초기 3건·next_id=4에서 한 번 생성하였으므로 실제 ID는 4였습니다.

| 동작 | 예상 | 실제 | 파일 확인 |
|---|---|---|---|
| 정상 등록 | 201·새 ID | 201·id=4 | 4건·next_id=5 |
| 같은 ID 조회 | 200·같은 내용 | 200·일치 | 변경 없음 |
| 본문 PUT | 200·같은 ID | 200·본문 변경 | 개수 4·next_id=5 유지 |
| 없는 ID PUT (정상 Body) | 404 | 404 | 바이트 불변 |
| 빈 content POST | 422 | 422 | 바이트 불변 |
| 같은 ID DELETE | 204·본문 없음 | 204·0바이트 | 3건·next_id=5 |
| 삭제한 ID GET | 404 | 404 | 변경 없음 |

이 시점의 JSON 상태는 운영검수/live_teacher_A.json의 guided_end에 있습니다.
다음 프로젝트는 이 상태에서 계속했으므로 첫 새 ID는 4가 아니라 5입니다. ID를 외워서 호출하지 않습니다.
