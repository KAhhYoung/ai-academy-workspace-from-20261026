# 강사 운영 메모

이 과제는 사용자·주제·본문을 수강생이 결정합니다. 하나의 정답 문장이 있는 과제가 아닙니다.
기본필수에게 미완성인 CRUD만 보완하게 하고, 이미 완료한 코드를 억지로 다시 작성시키지 않습니다.
6분 안내 후 40분 수행, 마지막 4분은 대표 1명 시연과 공통 피드백으로 마무리합니다.
기본 100점 기준은 PPT와 동일합니다. 심화 테스트를 기본필수에게 강제하지 않습니다.

가상 예시: 우리 반 학습 도우미 / A 파일 보관(learning), B 질문 방법(help), C 임시 공지(help).
B의 본문은 "질문을 메모합니다."에서 "오류 메시지와 함께 질문합니다."로 바꿀 수 있습니다.
3개 POST의 실제 id를 기록합니다. A/B/C를 4/5/6으로 고정하지 않습니다.
실습07에서 지식을 추가·삭제했더라도 현재 개수 N과 next_id를 기준으로 이어갑니다.

심화 test_daily_project.py는 임시 파일의 고정 가상 예시입니다. 수강생의 실제 주제·재시작 검증을 대신하지 않습니다.
이번 패키지 검수의 실제 샘플 결과는 강사용/운영검수에 따로 제공합니다. 수강생 실제 기록으로 복사하지 마세요.
