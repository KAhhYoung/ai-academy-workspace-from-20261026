## 1. Executive Summary

본 실습에서는 **예측 박스 4건**과 **정답 박스 3건**에 대해 IoU 0.50 기준의 일대일 매칭을 수행하고 오류를 유형별로 분류하였다. 집계 결과 **TP 2건, FP 2건, FN 1건**이며, 이를 바탕으로 계산한 **Precision 50.00%, Recall 66.67%, F1-score 57.14%**이다.

FP 2건은 **중복 탐지(Duplicate) 1건**과 **배경 오탐(Background_FP) 1건**으로 구분된다. IoU가 0.816229인 예측도 기존에 다른 예측과 연결된 정답을 다시 탐지한 경우이므로 FP로 처리되었다. **핵심 발견사항은 'IoU가 높아도 중복 매칭이면 TP가 아니다'**라는 점이다.

**평가 결론:** 제공된 출력은 예상 결과와 일치하여 **오류 분류 실습의 로직 검증 예시로는 적합**하다. 단, 이 결과는 손으로 구성한 Fixture에 근거하므로 실제 YOLO 모델의 정확도·mAP 또는 운영 적합성을 나타내지 않는다.

| 항목 | 적용 조건 |

| 관찰 단위 | 예측 박스별 매칭 결과 및 FP 유형; 미매칭 정답은 별도 FN 집계 |

> **자료 검증 범위:** 압축파일의 예상 출력과 사용자가 제시한 실행 결과가 일치하는 것을 확인했다. 단, 압축파일에는 원본 박스 CSV(`boxes_fixture.csv`, `boxes_gt.csv`)와 외부 매칭 구현(`provided/metrics.py`)이 포함되지 않아 좌표 계산 및 매칭 알고리즘 전체를 독립 재실행·검증하지는 않았다.

## 3. 주요 평가 결과

### 3.1 정량 지표

| 지표 | 계산식 | 값 |
|---|---|---:|
| 예측 박스 수 | TP + FP | **4건** |
| 정답 박스 수 | TP + FN | **3건** |
| True Positive (TP) | 매칭 성공 | **2건** |
| False Positive (FP) | 중복 또는 정답 미대응 예측 | **2건** |
| False Negative (FN) | 매칭되지 않은 정답 | **1건** |
| Precision | TP / (TP + FP) = 2 / 4 | **50.00%** |
| Recall | TP / (TP + FN) = 2 / 3 | **66.67%** |
| F1-score | 2TP / (2TP + FP + FN) = 4 / 7 | **57.14%** |

※ 위 값은 **이 Fixture의 단일 IoU 기준에서 계산한 Precision·Recall·F1**이며, mAP 또는 통상적인 여러 confidence 임계값을 이용한 탐지기 성능평가와는 다르다. 또한 **FP 비율 2/4 = 50%**를 False Positive Rate(FPR)라고 부르지 않는다. FPR 계산에는 TN이 필요하다.

### 3.2 예측별 상세 판정

| Prediction Index | Best IoU | 판정 | 해석 |
|---:|---:|---|---|
| 0 | 0.902500 | **TP** | IoU 기준을 충족하고 미사용 정답에 매칭 |
| 1 | 0.816229 | **Duplicate (FP)** | IoU는 높으나 중복 탐지로 분류되어 TP 불인정 |
| 2 | 1.000000 | **TP** | 완전히 겹치는 박스로 정답 매칭 |
| 3 | 0.000000 | **Background_FP (FP)** | 정답과 겹침이 없어 배경 오탐으로 분류 |

**FN 1건**은 예측 리스트의 행이 아니라 **어떤 예측과도 매칭되지 않은 정답**에서 별도 산출된다. 따라서 위 4행에 별도의 `Miss` 행이 없더라도 FN이 1건일 수 있다.

### 3.3 오류 유형별 분포

| 유형 | 건수 | 비중(전체 예측 4건 기준) | 주요 관찰 |
|---|---:|---:|---|
| TP | 2 | 50.0% | 정상 매칭 |
| Duplicate FP | 1 | 25.0% | 같은 객체의 중복 검출 |
| Background FP | 1 | 25.0% | 정답과 겹치지 않는 검출 |
| Wrong_class FP | 0 | 0.0% | 관찰되지 않음 |
| Loose_box FP | 0 | 0.0% | 관찰되지 않음 |

## 4. 원인 해석 및 한계

| 관찰된 사실 | 가능한 원인 가설 | 검증 필요 항목 |
|---|---|---|
| 높은 IoU(0.816229)에서도 Duplicate 발생 | 동일 객체에 여러 예측 생성; 중복 제거 미흡 가능성 | 원본 예측 신뢰도, NMS 적용 유무 및 설정, 정답 매칭 순서 |
| Best IoU가 0인 Background_FP 발생 | 배경 패턴에 반응한 불필요한 박스일 가능성 | 실제 이미지, 예측 점수, 임계값 및 시각화 |
| FN 1건 발생 | 객체 미검출·신뢰도 필터링·매칭 실패 가능성 | 미매칭 정답의 이미지/좌표/클래스, 후보 예측 목록 |

위의 **관찰**은 결과 데이터로 확인되지만 **원인**은 아직 입증되지 않았다. 또한 이 실습의 오류 분류는 각 예측의 가장 높은 IoU 등을 활용한 규칙 기반 진단이며, 실제 모델의 모든 실패 원인을 완전하게 구분하는 방법은 아니다.

## 5. 개선 및 후속 검증 계획

| 우선순위 | 후속 조치 | 검증 방법 / 산출물 |
|---|---|---|
| P1 | 중복 예측 처리 확인 | 클래스별 NMS 전·후 FP/TP 비교표 및 시각화 |
| P1 | 미매칭 정답(FN) 추적 | 미검출 원본 이미지·GT 위치·예측 박스 확인 |
| P2 | Confidence Threshold 영향 비교 | 임계값별 Precision–Recall 변화 기록 |
| P2 | 클래스 불일치·박스 위치 오류 점검 | 클래스별 오류 건수, IoU 분포, 사례 이미지 |
| P3 | 실제 데이터셋으로 재검증 | 독립 Validation 결과, 클래스별 P/R, mAP50, mAP50-95 |

> **유의:** NMS나 신뢰도 임계값을 변경한다고 모든 오류가 자동으로 줄어들지는 않는다. 중복 탐지는 완화할 수 있지만, 설정에 따라 정탐도 제거되거나 미탐이 늘어날 수 있으므로 지표를 함께 비교해야 한다.

## 6. 종합 판정

| 평가 항목 | 판정 | 근거 |
|---|---|---|
| Fixture 출력과 예상 결과 일치 | **PASS (출력 일치)** | 4개 예측의 유형·IoU 및 TP/FP/FN 결과 일치 |
| 오류 유형의 정량적 설명 가능 여부 | **PASS** | Duplicate 1, Background_FP 1, FN 1로 구분 가능 |
| 실제 객체 탐지 모델 성능 확인 | **미평가** | 손계산용 Fixture이며 실제 YOLO 예측 결과가 아님 |
| 운영 적용 적합성 | **판정 보류** | 실제 이미지, 독립 검증, 임계값 및 mAP 평가 필요 |

**최종 결론:** IoU 0.5 기준의 일대일 매칭을 통해 정탐 2건, 오탐 2건, 미탐 1건을 확인했으며, 오탐은 중복 탐지와 배경 오탐으로 구분되었다. 본 실습은 **객체 탐지의 오류 집계 원리를 이해하는 데 유효**하나, 실제 모델 성능이나 개선 효과를 주장하기 위한 근거로 사용해서는 안 된다.
