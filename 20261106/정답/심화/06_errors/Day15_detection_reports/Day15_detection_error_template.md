## 3. 평가 지표 및 결과

| 지표 | 값 | 산출 근거 |
|---|---:|---|
| TP | [ ] | [정답과 매칭된 예측 수] |
| FP | [ ] | [매칭되지 않은 예측 수] |
| FN | [ ] | [예측과 매칭되지 않은 정답 수] |
| Precision | [ ]% | TP / (TP + FP) |
| Recall | [ ]% | TP / (TP + FN) |
| F1-score | [ ]% | 2TP / (2TP + FP + FN) |
| mAP50 (선택) | [ ] | [실제 탐지기 검증 시에만 기재] |
| mAP50-95 (선택) | [ ] | [실제 탐지기 검증 시에만 기재] |

**계산 검증:** `TP + FP = 예측 박스 수`, `TP + FN = 정답 박스 수`인지 확인한다. 평가 정책에 따라 집계 방식이 달라졌다면 설명한다.

> **주의:** IoU 단일 기준에서 구한 Precision/Recall/F1과 mAP는 별개의 지표이다. 실제 측정하지 않은 mAP는 빈칸 대신 **미평가**로 표시한다.
