# 사전학습 가중치 위치

최초 `python check_setup.py` 또는 `python main.py` 실행 시 공식 `yolo26n.pt`를 이 폴더로 다운로드합니다. **현재 ZIP에는 모델 가중치가 없습니다.** 인터넷 연결이 없는 교실이라면 강사가 먼저 준비한 공식 파일을 `weights/yolo26n.pt`에 놓으세요.

공식 모델: https://docs.ultralytics.com/models/yolo26/  
자동 다운로드 안내: https://docs.ultralytics.com/quickstart/

추가 학습의 best.pt는 `outputs/train_.../weights/`에 별도로 저장됩니다. 기본 사전학습 파일을 덮어쓰지 않습니다. 출처를 모르는 `.pt` 파일은 실행하지 않습니다. 외부 모델/라이브러리의 이용·재배포 조건은 해당 배포처에서 확인하세요.
