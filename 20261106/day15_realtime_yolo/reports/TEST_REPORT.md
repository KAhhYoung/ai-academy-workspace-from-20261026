탐지 결과를 보면서 저장할 프레임을 고르면 선택 편향이 생길 수 있습니다. 잘 탐지된 순간만 저장하면 실제보다 성능이 높게 나옵니다. 반대로 실패 장면만 모으면 낮게 나오고요.

다만 거리·가림 조건을 사람이 설정하는 것 자체는 괜찮습니다. 중요한 것은 그 조건 안에서 탐지 성공 여부와 관계없이 평가 데이터를 수집하는 것입니다.

예를 들어 다음처럼 진행하세요.
1. 촬영 전에 조건과 수집량을 정합니다.
   예: 가위 A·B·C, 거리 50cm·1m·2m, 각 10초.
2. 각 조건에서 원본 영상을 정해진 시간만큼 저장합니다.
3. 미리 정한 규칙으로 프레임을 추출합니다.
   예: 각 영상의 시작부터 0.5초마다 한 장.
4. 추출된 프레임은 탐지 성공·실패와 관계없이 모두 라벨링하고 평가합니다.
수동 저장도 사전에 정한 시점에 결과와 무관하게 하면 가능하지만, 자동 저장이 편향을 줄이고 재현하기 더 쉽습니다.

지금 S 키로 저장하는 방식은 사례 관찰에는 유용하고, 성능 수치를 구할 평가 데이터는 별도로 일정한 규칙에 따라 수집하는 것이 좋습니다.
