# 보고서 문장 작성 예시

**아래는 표현 방식 예시이며, 실제 실행 결과가 아닙니다.** 자신의 캡처/로그가 뒷받침하는 내용만 사용하세요. 수치 예시를 실제 값처럼 복사하지 않도록 측정값은 빈칸으로 두었습니다.

## 1. 실행 성공과 성능을 구분

부적절: “프로그램이 잘 돌아가므로 정확도가 높다.”

작성 예: “사전학습 모델로 카메라 입력, 객체 탐지, 화면 표시와 증빙 저장이 정상 실행되었다. 이는 기능 실행 확인이며, 정답 라벨이 없어 Accuracy와 mAP는 측정하지 않았다.”

## 2. 관찰과 원인 가설을 구분

부적절: “모델이 어두운 사진을 학습하지 않아서 놓쳤다.”

작성 예: “일반 조명에서는 [클래스] 박스가 표시되었으나 조명을 낮춘 장면에서는 표시되지 않았다(증빙 [파일]). 조명 변화에 따른 영향으로 추정하지만, 촬영 각도/흐림도 바뀌어 원인을 확정할 수 없다.”

## 3. Confidence와 정확도를 구분

부적절: “Confidence가 0.90이므로 정확도가 90%다.”

작성 예: “해당 박스의 confidence는 [값]이었다. 이는 모델의 예측 점수이며, 전체 데이터의 정답률을 의미하지 않는다.”

## 4. 임계값 변경을 해석

부적절: “0.60으로 올리니 박스가 줄어 성능이 좋아졌다.”

작성 예: “임계값 변경 후 표시되는 박스가 줄었다. 일부 불필요한 탐지가 사라졌지만, 필요한 탐지도 제거되었는지는 별도 정답 라벨로 확인해야 한다.”

## 5. 속도 범위를 명시

작성 예: “`summary.json`의 predict 호출 평균은 [ ]ms, 처리 루프는 [ ]FPS였다. 전자는 전처리·후처리를 포함하며, 후자는 화면 표시 등도 포함한다. 서로 다른 PC의 값이므로 모델만의 우열로 해석하지 않았다.”

## 6. 결론 예시 구조

“이번 실습은 [모델/조건]으로 [물체/상황]을 관찰했다. [확인한 동작]은 확인되었으나 [한계]가 남아 있다. 현재는 제한된 조건의 기능 검증으로 판단하며, 다음 단계로 [검증 과제]를 수행한다.”
