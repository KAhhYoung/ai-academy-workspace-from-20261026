# 제작 시 검증 기록과 한계

확인일: 2026-11-06

## 실제로 확인한 항목

모든 Python 파일의 구문 검사를 수행했습니다. `python -m unittest discover -s tests -v`의 **15개 오프라인 테스트가 통과**했습니다.

테스트 범위는 데이터 YAML 해석, 정상 라벨, 빈 배경 라벨, 누락 라벨, 잘못된 class ID, 0 너비, 이미지 밖 박스, train/val 바이트 중복, 다른 폴더 구조, Test 미접근, 선택 학습/평가 호출부와 클래스 불일치 보호입니다.

사용자가 제공한 Day15 AVI를 **실제 OpenCV로 디코딩**하여 160×128 프레임 30장을 확인했습니다. 탐지 모델 대신 **모의 객체(FakeModel)** 를 사용한 별도 테스트에서 실제 영상 읽기, PNG 저장, 빈 검출 프레임 기록, CSV/JSON 생성, 리소스 정리 흐름을 실행했습니다.

`tests/OFFLINE_TEST_RESULT.txt`에는 테스트 이름과 통과 여부만 포함합니다. 모의 모델의 임의 점수나 처리 시간을 실제 성능 예시로 배포하지 않습니다.

## 실행하지 못한 항목

이 제작 환경에는 웹캠과 CUDA GPU가 없으며 Ultralytics가 설치되어 있지 않았습니다. 외부 네트워크 접근도 제한되어 패키지 설치와 공식 `.pt` 다운로드를 완료하지 못했습니다. 따라서 다음 사항을 실행 검증 완료라고 주장하지 않습니다.

- 실제 YOLO26 가중치 로딩 및 탐지 결과
- Windows 노트북 카메라 접근, GUI 키 조작과 화면 표시
- CUDA 실행 속도와 안정성
- 실제 사용자 데이터 학습 및 mAP 평가

실제 API 인자는 공식 문서를 확인하여 작성했지만, 문서 확인은 실행 테스트를 대체하지 않습니다. 가중치 파일은 ZIP에 포함하지 않았습니다. 최초 실행 자동 다운로드를 구현하고 오프라인 수업장의 준비 방법을 별도로 안내했습니다.

## 교실 사전 확인

```powershell
python -m pip install -r requirements.txt
python check_setup.py --camera 0
python main.py
```

실제 물체가 화면에 보이는지, S로 원본/주석 이미지가 저장되는지, Q로 종료한 뒤 summary.json이 만들어지는지 확인합니다. 선택 학습은 소규모의 올바른 라벨 데이터로 교사가 먼저 실행해야 합니다.

## 테스트 환경

Python 3.13.5 / Linux / torch 2.10.0+cpu / torchvision 0.25.0+cpu / opencv-python 4.13.0.92 / numpy 2.3.5 / PyYAML 6.0.3.

이는 **제작 환경의 로직 검사 버전**이며 사용자 수업 환경과 동일하거나 YOLO 통합 검증을 완료한 권장 고정 버전이라는 뜻이 아닙니다. 실제 수업 환경 버전은 `check_setup.py`와 `summary.json`에 기록합니다.
