# 지도·피드백 포인트

기본필수는 제공 데이터 로더와 전처리를 유지하며 회귀·분류 지표 함수와 후보 학습 흐름을 연결합니다. 독립 Pipeline 6개로 회귀 3행·분류 3행·valid 예측 120행을 생성합니다. test는 ID 확인 외에 모델에 전달하지 않습니다.

회귀 주 지표 RMSE로 Linear, 분류 주 지표 F1로 KNN3을 잠정 선택합니다. 회귀 MAE로는 KNN15가 더 낮고 Linear와의 RMSE 차이도 약 1.79ms에 불과하므로 한 지표의 작은 차이를 과장하지 않습니다.

응용은 K 탐색을 재실행하고 선택 Pipeline 두 개를 직접 저장하여 새 프로세스에서 복원합니다. 심화는 필수 열 누락·미지 범주·과도한 K·통계 불변 중 두 상황 이상을 검사합니다. 실습 08도 같은 프로젝트를 사용합니다.

정답 수치를 암기하게 하기보다 자신의 입력·단위·오류 사례를 근거로 설명하게 합니다. 기본필수의 목표를 먼저 확인하고 응용·심화를 강요하지 않습니다.
