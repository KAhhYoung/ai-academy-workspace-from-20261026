## 강사용 예시 답안

실행 전에 요청의 실패 여부와 실행시간을 각각 예측한다. 같은 train 60건·valid 20건, 입력 4열, train-only 전처리로 후보를 비교했다. 분류는 F1을 기준으로 KNN3(약 0.545), 회귀는 RMSE를 기준으로 Linear(약 640.00ms)를 잠정 선택했다. KNN3은 실패 6건 중 3건을 놓치며, 회귀는 MAE를 기준으로 하면 KNN15가 더 낮고 두 모델의 RMSE 차이도 약 1.79ms에 불과하다. 합성 자료·소표본·valid 반복 조회의 한계를 밝히고 test를 보관하며, 10월 27일의 트리·앙상블도 동일한 조건으로 비교한다.

오류 ID와 잔차는 `outputs/largest_regression_errors.csv`, `outputs/classification_errors.csv`에서 해당 실행 결과를 확인한다. Git 이력과 짝의 재실행 기록은 자동 생성하지 않으며 실제 수행한 내용만 적는다.
