# 실습 08 예상 결과

현재 시작값 N을 기록합니다. A/B/C 실제 ID는 서로 다르고, 정확히 3건 생성 COMMIT 뒤 N+3.
B ROLLBACK 뒤 원문, 다시 변경·COMMIT 뒤 새 연결에는 새 본문.
빈 본문(23514)·없는 분류(23503) 실패와 ROLLBACK 뒤 실패 전 행 내용/수가 동일합니다.
C 삭제·COMMIT 뒤 새 연결에서 C 0행, A·B 각각1행. 전체 N+2, 기존 행·A 원문 보존.
분류별 개수 합계=전체 지식 수. ID가 연속일 필요가 없습니다. SQL 0행을 HTTP 404로 표기하지 않습니다.
