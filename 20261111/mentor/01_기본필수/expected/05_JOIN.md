# 실습 05 예상 결과

S0 JOIN 3행(지식 한 건당 한 행), 분류별 learning 2 / environment 1 / reference 0.
세 그룹의 합계=knowledge 총 3행. 본문 길이 합계64/최소20/최대24.
응용 HAVING>=2 → learning 한 행.
심화 ON에 실습 제목 조건 → learning1/environment0/reference0 세 행;
같은 조건을 WHERE에 두면 learning1 한 행만 남습니다.
