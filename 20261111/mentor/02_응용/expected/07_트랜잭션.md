# 실습 07 예상 결과

임시 본문 변경 후 ROLLBACK → 시작 본문. 다시 변경·COMMIT 후 새 연결 → 실행 전에 가상환경을 확인합니다.
다른 원래 행은 그대로 남습니다(S1). 응용 두 변경 취소도 시작값 보존.
심화 두 번째 CHECK 실패 후 ROLLBACK이면 첫 변경까지 사라집니다.
인덱스 정의에 knowledge(category_id)가 추가됩니다. 동일 이름이 있으면 확인 후 생성 구간을 생략합니다.
Seq Scan도 정상이며 cost는 밀리초가 아닙니다. EXPLAIN ANALYZE는 여기서 SELECT만 실제 실행합니다.

이는 교안·SQL 계약으로 정한 예상값입니다. PostgreSQL에서 실제 실행한 결과는 따로 기록하세요.
