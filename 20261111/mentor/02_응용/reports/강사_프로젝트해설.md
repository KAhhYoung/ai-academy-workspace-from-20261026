# 일일프로젝트 해설 — 실제 실행 로그가 아닌 시연 설계

강사용 SQL의 가상 주제는 학습 안내입니다. A=학습 자료 보관, B=실습 결과 기록, C=폐기할 임시 안내입니다.
세 제목과 내용은 학생의 유일한 정답이 아닙니다. 목표 사용자가 분명하고 길이/참조 규칙을 만족하면 됩니다.

1. 시작 N과 기존 행 전체를 기록합니다. 시작 상태가 S1이라면 id 2에 이미 확정한 가상환경 안내가 있습니다.
2. A/B/C 생성의 실제 ID를 RETURNING에서 확인합니다. 예제에서 4·5·6이라는 번호를 정답으로 채우지 않습니다.
3. B를 임시 문장으로 바꾸고 ROLLBACK하면 B 원문, 다시 바꾸고 COMMIT하면 새 연결에서도 새 문장이어야 합니다.
4. 빈 본문은 CHECK(23514), 없는 분류는 FK(23503)가 목표입니다. 오류 뒤 ROLLBACK 후 전체 지식 행을 대조합니다.
5. C 한 행을 삭제·확정한 뒤 새 연결에서 A/B는 각각1행, C는0행이고 총 N+2입니다.
6. A의 원문과 시작부터 있던 모든 행은 그대로여야 합니다. 분류별 개수의 합계는 전체 지식 수와 같습니다.

실제 실행 전에는 ID·N·SQLSTATE·실행계획을 관찰값처럼 채우지 않습니다.
자신의 PostgreSQL에서 실행한 증거는 daily_note.md 또는 별도 검증 로그에 남깁니다.
