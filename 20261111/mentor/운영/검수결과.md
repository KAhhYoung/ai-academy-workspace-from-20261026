- 최신 Day18 84장 교안의 SHA-256을 source_manifest.json에 기록했습니다.
- 69·70장 공통 DDL과 실습 DDL이 public. 명시와 공백을 제외하고 동일함을 비교했습니다.
- 수강생용/강사용 과제 SQL **27쌍**, 구현 블록 **77개**를 대조했습니다.
  정답 블록을 대입하면 상대 파일 전체가 강사용과 정확히 일치합니다.
- 수준별 블록 수: 기본필수18 / 응용26 / 심화33. 학생 골격의 요구 주석과 정답 위치를 대응했습니다.
- 구간 ID·기대 SQLSTATE·괄호/문자열/주석 경계·미완성 정답 잔존·금지된 DROP/TRUNCATE·실행목록을 정적으로 확인했습니다.
- Python 보조 코드 AST 검사와 **14개 도구 단위 테스트**를 통과했습니다. PostgreSQL SQL 문법/실행 검사와는 다릅니다.
- 초기 한글 본문의 길이20·20·24와 합계64를 Python으로 다시 계산했습니다.

## 실제 DB 검증은 미실행
이 제작 컨테이너에 postgres·psql·initdb가 없고 DNS/외부 다운로드가 불가능했습니다.
verify_postgres.py의 실행 모드에서 psql 부재를 확인하여 **not_run**으로 기록했습니다.
PostgreSQL 설치·Windows·pgAdmin 버튼 조작·실제 SQLSTATE·DB COMMIT/ROLLBACK·DB 재접속을
직접 실행하여 확인한 상태가 아닙니다. SQLite 실행으로 PostgreSQL 검증을 대신 주장하지 않았습니다.

## 제공한 실행 검수 도구
실제 PostgreSQL용 검수 시나리오는 B92 / A105 / H118, 합계315개 실행 구간으로 구성되어 있습니다.
이 숫자는 **계획된 구간 수**이며 통과한 DB 테스트 개수가 아닙니다.
강사용 운영/README.md의 --run 명령으로 실제 서버에서 확인한 후 상태와 로그를 확인하세요.
새 검수 DB만 생성하며 수업 데이터는 초기화하지 않습니다. 같은 ID로 A/B/C를 자동 추적하고 새 연결도 확인하도록 작성했습니다.

## 범위와 주의
기본필수는 pgAdmin 수동 확인으로 충분합니다. 자동 검수 통과를 학생의 공통 만점 조건으로 추가하지 않습니다.
SQL 코드와 상태 전환 설계를 검토했지만 실제 DB 미검증 한계는 남아 있습니다.
다운로드·압축 무결성 검사와 실제 DB 동작 검사는 서로 다릅니다.
PPT와 기존 Day17 파일은 수정하지 않았습니다.
