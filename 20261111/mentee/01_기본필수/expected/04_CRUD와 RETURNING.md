# 실습 04 예상 결과

INSERT: 새 실제 ID·1행. ID 숫자는 고정 정답이 아닙니다.
기본필수 UPDATE id2 → 본문만 변경 1행, DELETE id3 → 삭제 1행, 각각 취소 뒤 원래 행이 복원됩니다.
응용·심화는 새 항목의 실제 __NEW_ID__를 사용해 같은 BEGIN에서 수정·삭제하고 마지막에 취소합니다.
없는 ID UPDATE는 0행입니다. 종료 후 전체 행의 ID·내용·개수가 시작과 같아야 합니다.
시퀀스 번호가 건너뛰는 것은 이 데이터 불변 검사의 실패가 아닙니다.

이는 교안·SQL 계약으로 정한 예상값입니다. PostgreSQL에서 실제 실행한 결과는 따로 기록하세요.
