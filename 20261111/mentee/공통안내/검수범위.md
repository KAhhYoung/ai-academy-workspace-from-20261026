# 검수 범위

이 자료는 최신 Day18 84장 교안의 두 테이블·초기 데이터·학습 순서에 맞춰 제작했습니다.
수강생/강사용 SQL 대응, 구현 블록 수, 실행 구간·문자열/주석 경계, 초기 데이터 수치를 정적으로 검수했습니다.
**실제 PostgreSQL 서버 실행과 Windows·pgAdmin 조작은 제작 환경에서 미검증입니다.**
강사용에 실제 PostgreSQL에서 실행할 수 있는 별도 검수 도구와 제작 검수 기록을 포함했습니다.
학생은 기본 SQL 학습을 위해 그 Python 도구를 실행할 필요가 없습니다.
예상 결과 문서를 실제 실행 증거로 제출하지 말고 자신이 관찰한 결과를 기록합니다.
