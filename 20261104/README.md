## 환경
기존 Python 가상환경을 재사용합니다. PPT의 목표 버전 OpenCV 4.14와 실제 검증 버전을 혼동하지 마세요.
이번 실제 검증: Python 3.13.5 · OpenCV 4.13.0 · NumPy 2.3.5 · Matplotlib 3.10.8 · Linux.
아래 설치는 역할 폴더(이 README가 있는 곳)에서 한 번만 합니다. 이미 설치되어 있으면 버전부터 확인합니다.

```powershell
python --version
python -m pip install -r requirements.txt
python -c "import cv2, numpy; print(cv2.__version__, numpy.__version__)"
```

`opencv-python`과 `opencv-python-headless`를 같은 환경에 새로 중복 설치하지 마세요. 배포 요구사항은 opencv-python 한 종류입니다.
다른 강의 환경을 덮어쓰는 대신 필요하면 별도 venv를 사용합니다. OpenCV CUDA·YOLO·TensorRT 설치는 오늘 필요하지 않습니다.
본 실습은 CPU로 동작합니다. `imshow` 창·웹캠·인터넷 다운로드를 사용하지 않으며 저장된 PNG를 파일 탐색기로 확인합니다.

## 데이터와 원본 보존
수업용으로 직접 생성한 합성 도형·색 패치·짧은 영상입니다. 외부 이미지·개인 데이터는 사용하지 않았습니다.
PNG는 정상 uint8, 기본 컬러 크기 320×240입니다. 영상은 MJPG/AVI, 48frame, 12FPS, 4초, 320×240입니다.
`noisy.png`의 점과 `objects.png`의 작은 구멍은 필터·형태학 개념을 위한 **정상 픽셀 패턴**입니다. 손상 파일이나 결측 데이터가 아닙니다.
기본필수 원본은 파일 옆, 상위 단계 원본은 data/에 있습니다. 원본 파일의 이름·내용을 변경하지 마세요.

## 실행 방법
ZIP을 완전히 해제하고 VS Code에서 폴더를 엽니다. 기본필수는 `01_기본필수/01_read.py`부터 시작합니다.
각 프로그램의 경로 준비 코드는 제공되어 있습니다. 입력 파일이 같은 위치에 있으면 다른 터미널 작업 폴더에서도 실행됩니다.
Windows의 코덱·경로 문제를 줄이기 위해 OpenCV에 영문 상대 파일명을 전달합니다. 해결되지 않으면 C:\ai_class 같은 영문 경로에서 다시 점검합니다.
Windows·macOS에서 직접 실행한 검증은 하지 않았습니다.

## 영상 관련 주의
VideoWriter/VideoCapture의 열림 값이 False이면 결과가 없는 것이므로 진행을 중지하고 강사에게 알립니다.
AVI 파일이 생긴 것만으로 성공이 아닙니다. 프로그램의 재읽기 Frame 수·FPS·크기도 확인합니다.
MJPG는 손실 압축입니다. PNG처럼 픽셀 완전 동일성을 요구하거나 Edge 영상의 모든 값이 0/255라고 단정하지 않습니다.
환경에 따라 코덱·파일 크기·시간이 달라집니다. 측정 시간과 drop 수는 정답 숫자가 아닙니다.
특심화 FFV1 검사는 해당 인코더가 없으면 skip으로 남기며 성공으로 포장하지 않습니다.

## 수업 운영
50분×8교시. 실습 배정은 01=20분, 02~07=각25분, 08=30분입니다. 나머지는 설명·시연·퀴즈·피드백에 사용합니다.
실습07과 08은 같은 프로젝트를 이어서 사용합니다. 학생 전원이 특심화 벤치마크까지 끝내는 것을 목표로 하지 않습니다.
기본필수만으로 공통 100점 기준을 충족할 수 있습니다. 높은 처리량·많은 Edge 수·복잡한 코드로 가산점을 강제하지 않습니다.
