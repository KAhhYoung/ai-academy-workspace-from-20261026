# 데이터 사전

수업용 합성자료100건입니다. 외부 고객/개인 데이터가 아닙니다.

| 열 | 의미 | 사용 |
|---|---|---|
| request_id | 고유 요청 ID | 정렬/분할검사만, 입력특성아님 |
| input_chars | 입력 문자 수, 결측 가능 | 실행전 입력 |
| allowed_tools | 허용 도구 수, 결측 가능 | 실행전 입력 |
| task_type | qa/research/summary, 결측 가능 | 실행전 입력 |
| priority | low/normal/high, 결측 가능 | 실행전 입력 |
| failed | 성공0/실패1 | 분류정답 |
| elapsed_ms | 실제 실행시간(ms) | 회귀정답, 입력금지 |
| retry_count·status | 실행후 재시도/종료상태 | 입력금지 |

split_manifest.csv는소속을, split_order.csv는분할내원래행순서를보존합니다. 새train_test_split을호출하지않습니다. checkpoints/train.csv·valid.csv는전처리되지않은복습용자료입니다. fixtures는앞단원부터재사용한잘못된입력예시이며실제학습에합치지않습니다.
