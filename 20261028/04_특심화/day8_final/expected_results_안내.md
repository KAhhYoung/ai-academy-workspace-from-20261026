# 예상 결과의 사용 범위

`expected_output.txt`는 강사용 정답을 `python main.py --save-model`로 처음 실행한 실제 출력입니다. 기본필수 실행에는 마지막 모델 저장 안내가 없습니다.

`expected_outputs/`는 기본 결과와 재현·제출 검증 기록이며, `expected_outputs_optional/`는 응용 모델 복원 대조 자료입니다. 학습된 모델 자체는 넣지 않았습니다. 이 디렉터리의 파일을 자신의 `outputs/`로 복사하거나 계산을 대신하는 입력으로 사용하지 않습니다.

동결 설정·receipt·metadata의 해시는 강사용 코드와 검증 환경에서 만들어졌습니다. 수강생이 작성한 코드에서는 해시가 다른 것이 정상입니다. 자신의 프로그램으로 생성한 lock과 자신의 코드 사이의 일관성을 검사하세요.

PPT와 예상 결과에 test 성능이 이미 공개되어 있으므로 수업 활동은 교육용 재현입니다. 새 후보의 독립적인 연구 성능이라고 주장하지 않습니다.
