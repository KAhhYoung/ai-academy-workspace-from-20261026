# 실습 06 · 심화 · 동결변경감지

PPT: **66·73 / E17~E19**. 기본필수부터 수행하고 응용·심화는 선택적으로 확장합니다. 한 시간에 세 단계를 모두 끝내야 하는 과제가 아닙니다.

## 목표와 범위
후보 목록과 선택 규칙을 먼저 기록하고, 설정 파일을 저장한 다음 새 Pipeline을80건으로 학습합니다.

수강생용: main.py의 NotImplementedError가 있는 함수만 우선 완성합니다. 입력과 실행 골격은 제공되어 있습니다.

## 입력과 구현 계약
외부 다운로드나 API 호출은 없습니다. 작은 수치 예제는 main.py에, 공통 요청100건과 고정 분할은 역할 폴더의 data/에 있습니다. 제공 로더는 train60·valid20만 반환하고 test는 설정 확정 단계 전 모델에 전달하지 않습니다.

- `reject_changed_lock(out)` — [D8-06H] out의임시복사본에서threshold를.3으로바꾸고검증이ValueError인지확인.

## 실행
역할 폴더를 VS Code의 **폴더 열기**로 열고, 같은 폴더에서 다음 명령을 실행합니다. Python 환경은 최상위 README를 따릅니다.

```text
python "ex06_freeze/03_심화/main.py"
python tools/check_practice.py --exercise 6 --level advanced
```

실제 출력은 이 실습 폴더의 `outputs/`에 생성됩니다. 실행 중 생성한 파일을 `expected_outputs/`에 복사하여 맞추는 것이 아니라, 소스코드로 다시 만들어야 합니다.

## 완료 기준
원본보존·임시파일에서threshold변경검출

출력 파일: **기본출력 + tamper_check.json**. `expected_output.txt`는 정답 코드의 실제 표준출력이고, `expected_outputs/`는 실제 생성한 예시 파일입니다. 검사는 부동소수점 허용오차를 사용합니다. 환경이나 실험 조건을 바꾼 결과는 별도 실험으로 구분하세요.

## 힌트와 점검
해시검사는우발변경감지용입니다. 교육용절차통제이며악성사용자를막는접근권한시스템은아닙니다.

이 단계부터 공개된 교육용 test20을 사용합니다. 결과를 본 뒤 새로운 후보/임계값을 골라 같은 test를 최종 독립 평가처럼 보고하지 않습니다. 같은 동결 설정의 재실행은 재현 검사입니다.
