## 처음 한 번: 환경 준비

10월 27일에 사용한 Python 3.13 가상환경을 그대로 사용해도 됩니다. 필요할 때만 이 README와 requirements.txt가 있는 폴더에서 다음을 실행합니다.

**Windows PowerShell**

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe "01_기본필수/01_metrics.py"
```

**macOS / Linux**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python "01_기본필수/01_metrics.py"
```

VS Code에서는 이 폴더를 **폴더 열기**로 연 다음 `Python: Select Interpreter`에서 `.venv`의 Python을 선택합니다. 이후 단계별 README의 `python 파일명.py`는 선택한 가상환경을 사용하는 터미널 기준입니다. 경로에 한글·공백이 있으면 전체 경로를 따옴표로 묶으세요.

기본필수·응용은 XGBoost·GPU·Matplotlib이 필요하지 않습니다. 심화 종합 프로젝트만 추가로 다음을 설치합니다.

## 꼭 구분할 것

**이번 수업은 그동안 보관한 test를 최종 확인하는 날입니다.** 설정 기록 전에는 test를 학습·선택에 쓰지 않습니다. 기본필수·응용은 `06_plan.py → 07_project.py`, 심화는 `plan.py → main.py → restore.py` 순서입니다. 기본필수·응용의 계획 파일은 변경 방지를 강제하는 보안 장치가 아니라 기록입니다. 최종 평가 후 파일과 후보를 임의 변경하지 않는 수업 규칙을 지킵니다.

PPT와 README에 최종 결과가 이미 공개된 **교육용 재현**입니다. 실제 서비스의 블라인드 성능 검증이 아닙니다. 결과를 본 후 후보·특성·임계값을 바꿔 같은 test로 다시 고르면 그 점수를 새 독립 평가라고 할 수 없습니다. 성능이 낮아도 올바르게 계산·설명하면 완료입니다.

미완성 코드에는 TODO 위치의 임시 0·pass가 있습니다. 작성 전에는 일부 출력이 0이거나 학습되지 않았다는 오류가 날 수 있습니다. 별도의 예외처리 과제가 아닙니다. TODO를 먼저 작성한 뒤 예상 결과를 대조하세요. 실행 종료만으로 정답으로 판단하지 않습니다.
