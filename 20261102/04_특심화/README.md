# 특심화 · 교시별 독립 실습 01~08

01~08은 매 교시의 CNN 주제에 대응합니다. 한 통합 프로젝트에 TODO만 늘린 구조가 아닙니다. 각 폴더에 tasks.py·run.py·support.py·tests·expected·reports가 있고, 필요한 입력도 자체 포함합니다. 서로의 정답/생성 파일/부모 공통 모듈을 import하지 않습니다.

|교시|폴더|목표|구현 항목|
|---|---|---|---:|
|1|`특심화01_메모리형식과_동등성`|메모리 형식과 출력·gradient 동등성|2|
|2|`특심화02_그룹합성곱과_연산량`|일반·그룹·Depthwise·Dilated 합성곱|2|
|3|`특심화03_Hook과_상태보존`|Forward hook과 상태 보존|2|
|4|`특심화04_DataLoader와_재현성`|DataLoader와 순서·Worker 재현성|2|
|5|`특심화05_AMP와_기울기누적`|AMP·불균등 기울기 누적·평가|2|

|8|`특심화08_체크포인트와_학습재개`|체크포인트·독립 프로세스 학습 재개|3|

총 8실습·18개 구현 항목입니다. 07·08의 세 번째 항목은 선택 확장/통합 검증입니다. 수업 중에는 현재 교시의 문제에 집중하고 더 필요한 검증은 확장 활동으로 이어갑니다.

## 단독 실행
선택한 폴더 전체를 복사한 뒤 그 폴더에서 다음을 실행합니다.
```powershell
python -m unittest discover -s tests -v
python run.py
```

04의 `--workers 2`, 07의 `--profile`은 선택 실행입니다. 06 기본 실행은 `weights=None` 구조 검사이며 실제 사전학습은 `--pretrained`로 분리합니다. 08은 자체적으로 새 프로세스 학습을 구성하므로 07의 checkpoint가 없어도 실행됩니다.

함수별 요구사항 주석이 구현 계약입니다. 오류가 나더라도 모델 상태·모드·난수·원본 보존을 요구한 경우 숫자만 맞추면 완료가 아닙니다. reports/review.md에 실제 검증 범위와 한계를 남깁니다.
