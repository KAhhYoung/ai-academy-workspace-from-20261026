## 구현할 부분

**D03**: 평가 모드로 바꾼 뒤 동일 입력 출력과 BN 상태를 확인한다. 힌트: eval()은 mode를 바꾸며 gradient 설정과는 별개다..

## 입력·출력

입력: `../day11_image_classification/data/`의 train/valid 또는 코드에 주어진 정상 Tensor. test는 사용하지 않습니다. 출력은 이 실습의 `outputs/`입니다. 비교용 결과는 `expected/`에서 확인합니다.

```text
train 출력 동일: False
BN 통계 변화: True
eval 출력 동일: True
shape: (4, 2)
```

### 완료 기준·기록

1. 바꾼 조건

모델의 실행 모드를 학습 모드(train())에서 평가 모드(eval())로 변경하였다.

학습 모드: Dropout이 활성화되어 동일 입력에서도 출력이 달라질 수 있으며, BatchNorm의 이동 통계가 갱신된다.

평가 모드: Dropout이 비활성화되고 BatchNorm은 학습 과정에서 저장된 이동 통계를 사용한다.

2. 고정 조건

① 입력 데이터: 동일한 입력 텐서 x를 사용하였다. 입력 Shape는 (4, 3, 32, 32)이며, 이미지 4개, 채널 3개, 높이와 너비가 각각 32픽셀이다.

② 모델 구조 및 파라미터: 동일한 SmallCNN(batchnorm=True, dropout=0.3) 모델을 사용하였으며, 실습 과정에서 가중치를 학습하거나 변경하지 않았다.

3. 관찰과 한계

관찰 결과

train 출력 동일: False → 학습 모드에서 Dropout의 무작위 적용으로 동일 입력에 대한 출력이 달라졌다.

BN 통계 변화: True → 학습 모드에서 순전파를 수행하면서 BatchNorm의 이동 평균 통계가 갱신되었다.

eval 출력 동일: True → 평가 모드에서는 Dropout이 비활성화되고 BatchNorm의 저장된 통계를 사용하므로 동일 입력에 대해 동일한 출력이 생성되었다.

shape: (4, 2) → 입력 Shape (4, 3, 32, 32)가 모델을 통과하여 (4, 2)로 변환되었다. 이는 각 이미지에 대해 2개의 출력값이 생성되었음을 의미한다.

일반화의 한계

무작위로 생성한 입력 데이터 4개와 학습되지 않은 단일 CNN 모델을 대상으로 수행한 실험이므로, 실제 이미지 데이터에서의 분류 성능이나 모델의 일반화 성능을 판단하기 어렵다.

결론

BatchNorm과 Dropout은 학습 모드와 평가 모드에서 서로 다르게 동작하며, 모델 평가 시 model.eval()을 호출하는 것이 중요함을 확인하였다.
