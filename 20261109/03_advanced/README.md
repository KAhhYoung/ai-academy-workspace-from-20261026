# Day16 · 심화

코드 난이도는 이전 응용 수준입니다. 실습01~06에서 제공 모듈을 활용하고, 07~08은 `day16_documents`를 이어서 사용합니다.

| 위치 | 할 일 |
|---|---|
| 실습01_전처리 | 실제 기록의 후보별 CER 선택 |
| 실습02_품질평가 | CER·필드 정확도 분리 |
| 실습03_표추출 | 고정 3행 표·합계 관계 |
| 실습04_VLM근거 | 라벨·값·근거 대조 |
| 실습05_Hybrid평가 | 응답 커버리지·보류·정확도 분리 |
| 실습06_엣지설계 | Jetson·DeepStream 측정 설계 |
| day16_documents | fields.py의 C07~C09와 main.py의 C10 완성 |

각 실습의 README를 읽고 `python experiment.py`를 실행합니다. 공통 입력은 `data/`이며 결과는 각 실습의 `outputs/`입니다. 예상 결과는 `expected/`입니다.

**의존 관계:** 실습01~02는 제공된 평가 모듈만 사용해 독립 실행됩니다. 실습03~05는 `day16_documents/fields.py`의 C07~C09가 필요합니다. 강사가 해당 수강생에게 완성 모듈을 먼저 제공해도 됩니다. 상위 실습을 모두 다시 작성해야 하는 구조가 아닙니다.

공개 테스트·복잡한 입력 계약은 특심화의 선택 범위입니다. 기본필수와 응용에 같은 부담을 추가하지 않습니다.
