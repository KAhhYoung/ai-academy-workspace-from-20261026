# 공식 참고자료와 적용 범위
검토일: 2026-10-26. 강의일은 2026-11-09입니다. 설치 환경이 달라지면 아래 공식 문서를 다시 확인합니다.

- Python-tesseract: wrapper/engine 분리, image_to_data·Output·BGR/RGB·TSV. https://pypi.org/project/pytesseract/
- Tesseract: 전처리·PSM·표 인식 한계. https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html
- Tesseract 설치: https://tesseract-ocr.github.io/tessdoc/Installation.html
- Hugging Face Transformers: 멀티모달 Processor·Chat template·generate. https://huggingface.co/docs/transformers/en/chat_templating_multimodal
- TensorRT 10→11 trtexec 변경: --fp16 등 제거와 사전 ONNX 정밀도 변환. https://docs.nvidia.com/deeplearning/tensorrt/latest/api/migration/tensorrt-10x-to-11x-trtexec.html
- TensorRT 지원 조합·엔진 이동 제약: https://docs.nvidia.com/deeplearning/tensorrt/latest/getting-started/support-matrix.html
- Jetson/JetPack 조합: https://docs.nvidia.com/deeplearning/tensorrt/latest/api/migration/tensorrt-10x-to-11x-jetson.html
- DeepStream Plugin 개요: https://docs.nvidia.com/metropolis/deepstream/dev-guide/text/DS_plugin_Intro.html

API를 확인한 것과 해당 장비에서 실행한 것은 다릅니다. 실제 VLM/TensorRT/Jetson/DeepStream 결과 수치는 이 자료에 없습니다.
