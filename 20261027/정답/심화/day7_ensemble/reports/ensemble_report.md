# 앙상블 실험 보고서 · 강사용 예시

이 문서는 실제 실행 결과의 해석 예입니다. 학생의 독립적인 판단을 대신하는 유일한 정답은 아닙니다.

## 1. 문제·데이터
요청 실행 전에 실패1을 예측하는 분류와 실행시간(ms) 회귀를 별도로 비교했습니다. 입력4열은 예측 시점에 알 수 있는 정보입니다. 전날의100건과 고정 ID·순서를 유지했고 train60·valid20·test20을 사용했습니다. test는 ID 관리 외 모델에 전달하지 않았습니다.

## 2. 사전에 정한 선택 규칙
train60 안의 동일5-fold 평균 F1 최대 / 회귀 평균 RMSE 최소를 사용했습니다. 동점이면 명시된 후보 순서가 앞선 모델을 선택합니다. valid는 별도 진단이며 최종 성능이 아닙니다.

## 3. 근거 3개
1. 분류 **Tree**의 CV F1은 **0.5424**, fold 편차는 **0.1236**로 선택되었습니다. 그러나 valid F1은 **0.3333**이며 실제 실패6건 중 **2건**만 발견했습니다.
2. KNN3의 valid F1은 **0.5455**로 Tree보다 높지만, CV F1은 **0.3356**입니다. 이 결과를 보고 사전에 정한 CV 선택 규칙을 valid 최고값 선택으로 바꾸지 않았습니다. 소표본에서 순위는 다를 수 있습니다.
3. 회귀 **KNN15**의 CV RMSE는 **598.850ms**, valid RMSE는 **641.788ms**입니다. 회귀 오차를 분류 F1과 평균내지 않았습니다. Tree·Forest·XGB라는 모델명이 기존 모델보다 우수함을 보장하지 않았습니다.

## 4. 실제 오류 사례
분류 FP: **R073**, 실제0·예측1, 실패 확률 **0.7143**. 불필요한 경고 비용이 발생할 수 있습니다.
분류 FN: **R044**, 실제1·예측0, 실패 확률 **0.0000**. 실제 실패를 놓친 사례입니다.
회귀 큰 오류: **R034**, 실제 **2608.0ms**, 예측 **1327.267ms**, 잔차(실제−예측) **1280.733ms**입니다.

## 5. 중요도와 한계
중요도는 선택된 Tree가 아니라 Forest의 별도 진단입니다. MDI는 train 학습 중 변환8열의 불순도 감소, 순열은 valid20에서 원본4열을 섞은 F1 감소입니다. 음수 순열 값도 숨기지 않습니다. 큰 중요도를 인과관계로 해석하지 않았고, 이 표로 특성을 선택한 뒤 같은 valid를 독립 평가라고 부르지 않았습니다.

## 6. 재현과 평가 정책
main.py의 생성 결과를 restore.py의 ID·예측·확률과 대조합니다. 버전·설정·분할·소스 변경을 기록합니다. 합성 자료100건·CV별 평가12건·바깥 valid20건이라는 소표본, 이전 수업부터 valid를 여러 번 관찰했다는 선택 편향을 명시합니다. 최종 test는 다음 평가 단계까지 보관합니다.
