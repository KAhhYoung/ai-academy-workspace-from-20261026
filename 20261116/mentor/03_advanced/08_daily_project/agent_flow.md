1. 사용자로부터 API 호출 및 질문•요청을 입력받는다.
2. DB를 통해 권한이나 로그인 관련 정보, 질문에 대한 답변을 구성할 지식 정보를 조회한다.
3. 조회한 지식 정보를 원본 수정으로부터 보호하기 위한 고정 스냅샷을 남긴다.
4. 스냅샷을 사용하여 컨텍스트를 구성한다.
5. 다음의 정보를 조합하여 프롬프트를 생성한다.
  - 질문
  - 지식 데이터(컨텍스트)
  - 지시
  - 출력계약
  - 예제
6. 작성한 프롬프트 구성항목을 최소 범위로 수정하여 A,B를 비교 테스트한다.
 1) 테스트 결과는 기록으로 남긴다.
7. 선택된 프롬프트를 LLM 에게 전달하여 응답을 받는다.
8. 출력된 응답에 대해 다음을 검증한다.
  - JSON 문법확인
  - schema 구조확인
  - 참조•상태 규칙 검증
  - 사람의 근거 검토
9. 형식 오류에 대한 재시도 / 중단을 설계한다.
 1) 재시도: 프롬프트 생성과정을 재진행한다.
10. 출력 검증 통과 시, 사람의 근거 검토를 거친다.
11. 근거 검토 통과 시, API 응답을 통해 사용자에게 결과를 반환한다.
