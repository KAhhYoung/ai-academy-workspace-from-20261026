# CNN 모델 폭(Width) 변경에 따른 성능 비교 실험 보고서

**실습명:** 모델 폭 비교 · 심화 (D05)  
**참고 자료:** PPT 58쪽  
**실험 목적:** 동일한 데이터셋과 학습 조건에서 CNN 모델의 폭(Width)을 8과 16으로 변경했을 때 분류 성능 및 파라미터 수에 미치는 영향을 분석한다.

## 1. 실험 개요

본 실험은 CNN 모델의 구조적 요소 중 하나인 **모델 폭(Width)** 이 분류 성능에 미치는 영향을 확인하기 위해 수행하였다.

동일한 데이터셋, 학습 횟수 및 하이퍼파라미터를 유지하면서 모델의 폭을 8과 16으로 변경하여 학습하고, 검증 손실(Validation Loss)과 정확도(Accuracy)를 비교하였다.

### 1.1 실험 환경 및 조건

| 항목 | 실험 조건 |
|---|---|
| 모델 | SmallCNN |
| 비교 모델 | small_w8, small_w16 |
| 변경 변수 | 모델 폭(8 → 16) |
| 데이터셋 | 동일한 train/valid 분할 |
| 입력 이미지 | 32 × 32 픽셀 |
| 배치 크기 | 16 |
| Epoch | 3 |
| Optimizer | AdamW |
| Learning Rate | 0.01 |
| Weight Decay | 0.0001 |
| Random Seed | 42 |
| 사전학습 가중치 | 사용하지 않음 |
| 평가 기준 | 검증 손실, 검증 정확도 |

### 1.2 모델 비교 설정

```python
# 모델 구조는 동일하게 유지하고 폭만 변경
SETTINGS = [
    ("small", 8, 3),
    ("small", 16, 3)
]
```

두 모델 모두 3 Epoch 동안 학습하며, 검증 손실이 가장 낮은 Epoch의 가중치를 최종 모델로 선정하였다.

## 2. 실험 결과

### 2.1 모델별 최종 성능 비교

| 평가 항목 | SmallCNN (폭 8) | SmallCNN (폭 16) |
|---|---:|---:|
| 학습 가능 파라미터 | 1,426개 | 5,154개 |
| 최적 Epoch | 3 | 3 |
| 검증 손실 | 0.6068 | **0.3722** |
| 검증 정확도 | 65.0% | **95.0%** |
| 입력 이미지 크기 | 32×32 | 32×32 |

**주요 결과**

- 모델 폭을 8에서 16으로 증가시키자 학습 가능 파라미터가 약 3.61배 증가하였다.
- 검증 손실은 0.6068에서 0.3722로 약 38.7% 감소하였다.
- 검증 정확도는 65%에서 95%로 30%p 증가하였다.
- 두 모델 모두 검증 손실 기준 최적 Epoch는 3으로 확인되었다.

### 2.2 Epoch별 검증 성능 변화

| 모델 | Epoch | 검증 손실 | 검증 정확도 |
|---|---:|---:|---:|
| 폭 8 | 1 | 0.6600 | 50% |
| 폭 8 | 2 | 0.6152 | 75% |
| 폭 8 | 3 | 0.6068 | 65% |
| 폭 16 | 1 | 0.6195 | 95% |
| 폭 16 | 2 | 0.6283 | 50% |
| 폭 16 | 3 | 0.3722 | 95% |

**분석**

폭 8 모델은 Epoch가 증가하면서 검증 손실이 지속적으로 감소하였지만, 검증 정확도는 2 Epoch에서 75%를 기록한 뒤 3 Epoch에서 65%로 하락하였다.

폭 16 모델은 1 Epoch에서 95%의 정확도를 기록했으나 2 Epoch에서 50%로 감소한 후, 3 Epoch에서 다시 95%로 회복되었다.

이는 학습 과정에서 검증 정확도가 항상 단조롭게 증가하지 않으며, 검증 손실과 검증 정확도가 반드시 같은 방향으로 변화하는 것은 아님을 보여준다.

본 실험에서는 검증 정확도가 아닌 **검증 손실이 가장 낮은 Epoch의 모델**을 선택하였다.

## 3. 완료 기준 및 실험 조건 기록

### 3.1 바꾼 조건 1개

**변경 조건: CNN 모델 폭(Width)**

- 모델 A: width=8
- 모델 B: width=16

모델 폭을 증가시켜 학습 가능한 특징 표현의 규모를 변경하고, 이에 따른 검증 성능 차이를 비교하였다.

### 3.2 고정한 조건 2개

**① 데이터 조건 고정**

두 모델 모두 동일한 학습 및 검증 데이터 분할을 사용하였다. 입력 이미지 크기도 32×32로 동일하게 유지하였으며, 테스트 데이터는 사용하지 않았다.

**② 학습 조건 고정**

두 모델 모두 Epoch=3, Batch Size=16, Learning Rate=0.01, Random Seed=42 및 동일한 AdamW 최적화 조건을 사용하였다.

따라서 모델 간 성능 차이를 분석할 때 주요 변경 변수는 모델 폭이다.

### 3.3 입력 및 출력 Shape 비교

| 구분 | 폭 8 모델 | 폭 16 모델 |
|---|---|---|
| 원본 이미지 | RGB, 32×32 | RGB, 32×32 |
| 입력 배치 예시 | (16, 3, 32, 32) | (16, 3, 32, 32) |
| 출력 배치 예시 | (16, 2) | (16, 2) |
| 학습 파라미터 | 1,426 | 5,154 |

*Shape는 배치 크기 16, RGB 입력, 2클래스 분류를 가정한 예시이며, 마지막 배치는 샘플 수에 따라 크기가 달라질 수 있다.*

모델 폭이 증가하더라도 입력 이미지 크기와 최종 클래스 수는 동일하게 유지되므로 입력 및 최종 출력 Shape는 같으며, 모델 내부의 특징 표현 규모와 파라미터 수가 달라진다.

## 4. 실험 결과에 대한 종합 분석

### 4.1 성능 개선 분석

모델 폭을 8에서 16으로 증가시킨 결과, 검증 정확도가 30%p 상승하고 검증 손실이 감소하였다.

이는 해당 실험 조건에서 더 넓은 모델이 데이터의 특징을 효과적으로 표현하고 분류하는 데 유리하게 작용했을 가능성을 보여준다.

다만 모델 폭이 증가하면서 파라미터 수 역시 약 3.61배 증가하였으므로, 성능 개선과 함께 모델 크기 및 연산 비용을 고려할 필요가 있다.

### 4.2 실험의 한계

본 실험은 제한된 이미지 데이터셋과 단일 학습/검증 분할, 3 Epoch, 하나의 난수 시드로 수행하였다.

따라서 폭 16 모델의 성능이 더 높게 나타났더라도 모든 데이터셋과 학습 환경에서 더 넓은 모델이 항상 우수하다고 일반화하기는 어렵다.

또한 검증 데이터만 평가하였으므로 별도의 테스트 데이터에 대한 최종 일반화 성능은 확인하지 못하였다.

보다 신뢰성 있는 비교를 위해서는 여러 난수 시드를 활용한 반복 실험, 학습 Epoch 확대, 독립적인 테스트 데이터 평가 등이 필요하다.

## 5. 최종 결론

본 실험에서는 CNN 모델의 폭을 8에서 16으로 증가시켰을 때 검증 정확도가 65%에서 95%로 상승하고 검증 손실이 0.6068에서 0.3722로 감소하였다.

이를 통해 **모델 폭은 특징 표현 능력과 분류 성능에 영향을 줄 수 있는 주요 구조적 하이퍼파라미터**임을 확인하였다.

다만 모델 폭을 증가시키면 학습 가능한 파라미터 수도 함께 증가하므로, 실제 모델 설계에서는 검증 성능뿐 아니라 연산 비용, 메모리 사용량 및 과적합 가능성을 종합적으로 고려해야 한다.

**최종 평가:** 본 실험 조건에서는 폭 16 모델이 폭 8 모델보다 우수한 검증 성능을 나타냈으나, 일반화된 결론을 도출하기 위해서는 추가적인 반복 실험이 필요하다.
