# 특심화 · 교시별 독립 실습 01~08

한 통합 프로젝트의 TODO만 나누지 않았습니다. 각 폴더를 단독 복사해도 진행할 수 있고, 해당 교시 문제의 입력·시작 코드·검사를 자체 포함합니다. 이전 폴더에서 생성한 결과나 정답을 import하지 않습니다.

|교시|폴더|주제|구현 항목|
|---|---|---|---:|
|1|`특심화01_Packing과_순서복원`|Packing·정렬·역순열|2|
|2|`특심화02_RNNCell과_미분대조`|RNNCell과 BPTT 수치 대조|2|
|3|`특심화03_LSTM_Gate진단`|LSTM gate와 유효 시점 진단|2|
|4|`특심화04_재구성과_임계값`|재구성 손실과 임계값 선택|2|
|5|`특심화05_Attention과_Mask`|Self-Attention·Padding·Causal Mask|2|
|6|`특심화06_아키텍처_공정비교`|아키텍처별 공정한 평가|2|
|7|`특심화07_벤치마크와_Profiler`|성능 측정·상태 보존·Profiler|3|
|8|`특심화08_체크포인트와_학습재개`|체크포인트와 독립 프로세스 학습 재개|3|

총 8실습·18개 구현 항목입니다. 07의 세 번째 집계는 선택 확장, 08은 제공 실행기에 학습·저장·복원 세 함수를 연결합니다. 04의 최종test 명령은 선택 활동입니다. 수업 시간에는 현재 교시의 핵심 구현에 집중하고 남은 확장은 보고서 활동으로 이어갑니다.

```powershell
# 선택한 실습 폴더에서
python -m pytest tests -q
python run.py
```

`tasks.py` 함수 위의 요구사항이 구현 계약입니다. 입력·출력 수치뿐 아니라 원본/gradient/모드/난수 보존을 요구한 경우 그 검사도 통과해야 합니다. 모르는 함수의 문법은 짧은 도움말을 참고하고, 실제 문제 조건은 주석을 읽습니다. CPU로 기본 경로를 완성할 수 있습니다. CUDA 전용 테스트가 skip되면 통과가 아니라 미검증으로 기록합니다.
