## 수업 순서와 완료 기준
1교시 Padding → 2교시 RNN → 3교시 LSTM → 4교시 Autoencoder → 5교시 Attention → 6교시 아키텍처 비교 → 7교시 시간/메모리 → 8교시 통합·재현.
기본필수·응용은 상위 모듈을 직접 설계하지 않습니다. 심화는 제공 모듈을 연결하고, 특심화는 각 교시의 `tasks.py`를 구현합니다. 앞 교시 미완성이 다음 교시 진입을 막지 않도록 필요한 시작 코드를 포함했습니다.

## 데이터와 평가 정책
기본필수 원관측100개는 시간순60/20/20, 나머지 시계열 원관측300개는180/60/60입니다. 각 구간을 먼저 나눈 뒤 그 구간 안에서 Window를 만듭니다. 분류자료는 독립100개 Sequence의60/20/20 분할입니다. 코드가 모델에 전달하는 것은 train과valid뿐입니다. 예측·재구성·분류 지표를 합쳐 평균내지 않습니다.
특심화04의 이상탐지 확장만 별도 `anomaly_*.csv`를 쓰며, 정상train 학습→valid 임계값 동결→별도test 1회 평가 순서입니다. 기본 실행은 test 평가를 하지 않습니다. 공개된 교육 자료이므로 실제 외부 일반화 성능을 주장하지 않습니다.

## 실행·기록
각 README의 명령은 해당 폴더에서 실행합니다. 스크립트는 파일 위치 기준으로 입력을 찾으므로 다른 작업 디렉터리에서 절대 경로로 실행해도 됩니다. 특심화 테스트는 **각 폴더별로 별도 프로세스**에서 실행합니다. 이름이 같은 독립 모듈을 한 Python 프로세스에서 섞지 마세요.
CPU에서는 GPU 메모리를 0으로 쓰지 말고 N/A/None으로 기록합니다. 시간값은 기기·부하에 따라 달라집니다. `*.pt`는 제공하지 않으며 직접 실행해 생성한 신뢰 파일만 `weights_only=True`로 읽습니다.
