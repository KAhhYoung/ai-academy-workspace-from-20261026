## 실행 환경

Python 3.12, 동기 SQLAlchemy 2.0 및 psycopg 3이 기본입니다. 특심화의 비동기 비교는 별도 제공 코드를 사용합니다.
공통 requirements.txt를 한 번 설치합니다. PostgreSQL 서버는 별도로 준비합니다.
교재 기준 PostgreSQL 18, 실제 제작 검수 PostgreSQL 16.2입니다. 버전별 환경 한계는 검수보고서에 기록했습니다.
