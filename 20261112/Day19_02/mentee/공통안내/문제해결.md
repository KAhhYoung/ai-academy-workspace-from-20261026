# 문제 해결 순서

- `ModuleNotFoundError`: 프로젝트 Root·가상환경·설치 패키지 확인
- `psycopg` 없음: `python -m pip install "psycopg[binary]"`
- DB connection refused: PostgreSQL Service·Host·Port 확인
- password authentication failed: `.env`의 User·Password 확인
- database does not exist: 오전 수준에 맞는 DB 이름인지 확인
- 404: API Path 또는 실제 id 확인
- 422: Body 세 필드와 길이 확인
- 500/409 뒤 같은 요청이 계속 실패: rollback 처리 여부 확인
- 다른 데이터가 보임: `SELECT current_database(), current_user;`로 연결 대상부터 확인
