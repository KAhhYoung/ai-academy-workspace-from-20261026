# 실행 안내

1. 선택한 체크포인트 폴더를 VS Code로 엽니다.
2. `python -m venv .venv` 후 가상환경을 선택합니다.
3. `python -m pip install -r requirements.txt`
4. `.env.example`을 `.env`로 복사하고 DB 비밀번호와 연결 대상을 확인합니다.
5. `python -m uvicorn app.main:app --reload`
6. `http://127.0.0.1:8000/docs`에서 API를 호출합니다.
7. pgAdmin Query Tool에서 `sql/check_pm_start.sql` 또는 직접 SELECT로 같은 id를 확인합니다.

오전 FastAPI 서버가 남아 있다면 종료하고 오후 서버 하나만 실행하세요.
