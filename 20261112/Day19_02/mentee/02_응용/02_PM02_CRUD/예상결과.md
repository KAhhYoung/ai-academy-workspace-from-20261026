# 예상 결과 · PM02

| 요청 | 예상 API | DB 확인 |
|---|---|---|
| GET 목록 | 200 | 변경 없음 |
| GET 상세 | 200 / 없는 정수 ID는 404 | 변경 없음 |
| POST | 201 + 실제 id | 같은 id Row 1건 추가 |
| PUT | 200 + 같은 id | title/content/category_id 변경, 행 수 유지 |
| DELETE | 204 + Body 없음 | 같은 id 0행 |
| 빈 content POST | 422 | DB 접근 전 거부, 행 변화 없음 |

생성 id를 4로 고정하지 않습니다. 실제 응답의 id를 사용합니다.
