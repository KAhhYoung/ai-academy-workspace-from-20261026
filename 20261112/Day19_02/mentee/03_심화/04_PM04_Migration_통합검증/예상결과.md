# 예상 결과 · PM04

Migration 연습 DB에서:
1. `alembic upgrade 001_initial` → categories/knowledge 생성
2. `alembic upgrade head` → knowledge.source 추가
3. `alembic downgrade 001_initial` → source 제거
4. 다시 `upgrade head` → source 재추가

주 프로젝트에서는 `verify_link.py`가:
- API POST id와 DB 조회 id 일치
- API DELETE 204
- 삭제 후 DB remaining = 0
를 확인합니다.
