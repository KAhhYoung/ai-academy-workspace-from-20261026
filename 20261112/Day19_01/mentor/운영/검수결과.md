## 미검증 범위 — 실제 PostgreSQL 실행과 구분
**PostgreSQL 서버·psql이 설치되어 있지 않고 다운로드 접근도 불가능하여 실제 PostgreSQL SQL 실행은 검수하지 못했습니다.**
따라서 SQL 구문·제약조건 오류·트랜잭션의 서버 실행 성공을 주장하지 않습니다. SQL 예상표는 요구사항과 논리 대조 결과입니다.
강사는 실제DB_사전검수.md의 수동 점검 또는 선택 검수 도구로 실제 환경을 확인해야 합니다.
Windows·PowerShell 직접 실행, pgAdmin UI 조작, 신규 패키지 설치도 미검증입니다.
