ModuleNotFoundError 현재 폴더·Python 인터프리터 명세의 실행 위치와 requirements 확인

404 경로·실제 ID·Method /docs에서 등록된 요청과 입력 확인
422 detail의 loc Path/Body·필수 필드·길이 확인

DB 접속 실패 서버·Host·Port·계정·DB명 전날 정상 접속 설정과 비교; 보안 정책 변경은 하지 않음
relation already exists CREATE를 반복했는지 성공한 구축 파일은 다시 실행하지 않음
SQLSTATE 25P02 앞서 실행한 실제 오류 같은 Query Tool에서 ROLLBACK 후 재시도
TODO / __NEW_ID 문법 오류 구현 TODO인지 실행 입력인지 TODO는 SQL 완성, NEW_ID는 실제 반환 정수로 치환
결과 개수 불일치 S0 또는 변경 단계 상태 실행 순서·WHERE·ORDER BY 확인
기대 오류 대신 표 없음 DB·스키마 SELECT current_database()와 public 테이블 확인

DB 구축(A)이 막혔다고 CRUD(B)를 기다릴 필요는 없습니다. B의 완성 복원 SQL로 시작할 수 있습니다. DB 자체가 접속 불가라면 SQL 작성까지 진행할 수 있으나 실행 검증은 미완료입니다. 정상 0행 SELECT를 실패로 보지 않습니다. 실패한 문장의 오류코드가 명세와 같은지 확인합니다.
