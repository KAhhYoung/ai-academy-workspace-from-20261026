# 기본필수 · 두 실습의 시작점

오전에는 **실습 1 FastAPI 구현**, **실습 2 PostgreSQL 구축·CRUD**만 진행합니다.
50분마다 과제를 바꿀 필요는 없습니다. 한 수준을 골라 두 실습을 수행하며 쉬는 시간은 교육장 운영에 따릅니다.
API와 DB를 서로 연결하거나 두 저장소를 비교하는 보고서는 만들지 않습니다.

| 실습 | 먼저 열 문서 | 작성 대상 |
|---|---|---|
| 1. FastAPI | [API 명세서](01_FastAPI/명세서.md) → [예상 결과](01_FastAPI/예상결과.md) | Python 구현·검사 블록 6개 |
| 2. PostgreSQL | [실행 안내](02_PostgreSQL/README.md) → [ERD·스키마 명세](02_PostgreSQL/스키마명세서.md) | DDL 4개 + SQL 8개 |

**DB 구축이 막혀도 `B_CRUD/00_ready_database.sql`로 CRUD 실습을 시작할 수 있습니다.**
기본필수도 CRUD 전체를 다룹니다. 응용·심화는 직접 구현하는 범위와 파일 책임·검증의 깊이를 높입니다.
별도 장문 보고서는 없으며 문제 옆의 완료 기준으로 확인합니다.

이전 자료의 주제 선정·A/B/C 자유 작성·두 저장소 비교·오후 질문 제출 과제는 이번 v2에 포함하지 않습니다.
