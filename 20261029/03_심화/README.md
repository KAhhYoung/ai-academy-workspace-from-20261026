`data/`는 입력, `expected/`는 정답 실행에서 생성한 비교용 텍스트/수치, `outputs/`는 자신의 실행 결과, `reports/`는 자신의 설명입니다. expected 파일을 outputs로 복사해 제출하는 것은 구현 완료가 아닙니다. 모델 .pt는 배포하지 않습니다.

실습07에서 기본 파일 분리를 경험하되 복잡한 입력 검증이나 자동 테스트 작성은 요구하지 않습니다. CUDA 실제 측정과 엄격한 재개 검증은 특심화 선택 과제로 분리했습니다.


## 실습 08 추가 · 정상 입력의 자동 검증 2개

`day9_ann/tests/test_training.py`의 H11과 H12를 완성합니다.

* H11: 정상 7건을 3·3·1로 나누어도 lr=0의 배치 가중 손실과 전체 손실이 일치해야 합니다.
* H12: 평가 전후 파라미터·기존 gradient가 같고 예측값에 계산 그래프가 붙지 않아야 합니다.

```powershell
cd day9_ann
python -m unittest discover -s tests -v
```

추가 패키지 없이 표준 unittest를 사용합니다. 검증 데이터와 학습 코드는 제공되며 두 assert 블록만 작성합니다. 미완성 테스트는 명확하게 실패합니다. 단순히 print로 숫자를 출력하는 것은 통과 검사가 아닙니다. main.py나 이전 실습을 실행하지 않아도 이 두 테스트를 시작할 수 있습니다.
