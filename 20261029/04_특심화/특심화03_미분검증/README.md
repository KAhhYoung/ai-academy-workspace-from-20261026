# 특심화 03 · 해석 미분·수치 미분·Autograd

## 학습 목표와 범위
같은 MSE를 세 가지 독립된 방법으로 미분하고 허용오차 내 일치를 확인한다.

loss=mean((X@w+b-y)^2)의 미분을 직접 유도합니다. 해석 미분은 필수, 중앙 차분은 시간이 남으면 확장합니다. ReLU의 꺾이는 지점은 수치검증 예제로 사용하지 않습니다.

수업 실습 시간: 25분. 처음부터 모든 구현을 새로 설계하는 과제가 아닙니다. **수정할 파일은 `tasks.py`**이며 실행기·데이터·선행 코드·테스트는 제공합니다. 숫자를 하드코딩하거나 expected/를 읽어 결과를 만드는 것은 과제를 수행한 것이 아닙니다.

## 시작 파일과 구조
```text
특심화03_미분검증/

  tasks.py       # 이번 교시의 직접 구현 부분
```

07·08에는 로컬 `data/`와 완성된 선행 모델·엔진이 추가됩니다. 다른 실습 폴더나 상위 공통 코드를 import하지 않습니다. `outputs/`는 실행 시 만들어집니다.

## 실행 순서
VS Code에서 **이 폴더**를 엽니다. 기존에 확인한 PyTorch 인터프리터를 선택합니다.

```powershell
python -c "import torch; print(torch.__version__)"
python -m unittest discover -s tests -v
python run.py
```

1. 테스트 이름과 요구사항 주석을 먼저 읽고 예상 결과를 기록합니다.
2. TODO 구현 후 공개 테스트를 통과시킵니다. 실제 CUDA 전용 검사는 장치가 없으면 SKIP입니다.
3. run.py를 실행하여 `outputs/gradient_check.json`를 만듭니다.
4. expected/와 비교하고 reports/review.md에 확인한 범위와 한계를 적습니다.

테스트는 미완성 상태에서도 문법 오류가 아니라 구현 누락을 알려주도록 구성했습니다. 앞 실습이 미완성이어도 지금 폴더의 과제는 진행할 수 있습니다. 다른 위치에서 실행할 때는 `python "이 폴더의 절대경로/run.py"`를 사용합니다.

## 완료 기준
구현 ID 2개와 실제 생성 결과를 설명합니다. 공개 검사 3개 중 CPU 확인 가능 검사는 통과해야 합니다. 이번 제작 환경에서 CUDA 전용 미검증 검사는 0개입니다. 학습 수치 자체를 맞추기보다 원리·shape·상태·순서·허용오차를 확인합니다. 타 장치·버전의 bitwise 동일성을 보장한다고 보고하지 않습니다.
